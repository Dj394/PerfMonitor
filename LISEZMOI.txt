PerfMonitor Live - installation
================================
1. Decompressez TOUT le contenu de ce zip dans un dossier definitif (ex. C:\PerfMonitor ou Documents\PerfMonitor).
   L'application y ecrira ses reglages et son historique (dossier data\).
2. Double-cliquez sur Installer.cmd
   - acceptez l'invite "Controle de compte d'utilisateur" (l'application lit les capteurs en administrateur)
   - si PawnIO est propose, acceptez : sans lui, pas de temperature/ventilateurs CPU (le reste fonctionne)
   - SmartScreen au premier lancement : "Informations complementaires" puis "Executer quand meme" (exe non signe)
3. C'est tout : PerfMonitor demarre, se lance a chaque ouverture de session (icone dans la zone de notification)
   et se met a jour tout seul quand une nouvelle version sort.

Prerequis : Windows 10/11 64 bits + .NET 10 Desktop Runtime (https://dotnet.microsoft.com/download/dotnet/10.0, "Run desktop apps" x64).
Pas envie de l'installer ? Prenez le zip "portable" : meme chose, sans prerequis.

Desinstaller : Desinstaller.cmd (puis supprimer le dossier).
Un souci ? Onglet Machine > Copier, et le fichier data\live.log : https://github.com/Dj394/PerfMonitor/issues
